# Forklift Meter Platform

> [中文版](README.zh-CN.md)

A public instrument platform reference implementation for D133/reference-board. The Demo supports at least English and Simplified Chinese; fonts are generated by `lv_font_conv`, and DBC is the Source of Truth for protocols.

## Host

```sh
python -m pip install -r tools/protocol/requirements.txt
cmake -S . -B build -G Ninja -DMETER_BUILD_UI=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

Linux CI uses `ubuntu-latest`. Set `SDL_VIDEODRIVER=dummy` for SDL runs.

## Product package

The Demo lives in `products/demo` and can be copied to another repository via:

```sh
cmake -S . -B build-private -DMETER_PRODUCT_ROOT=/path/to/product
```

Scaffold a blank product template with:

```sh
python tools/create_product.py --id reference-b --output examples/reference-b
```

Reference-B is a second synthetic product example using CAN1, 29-bit extended frames, an independent DBC, independent stale times and a two-page LVGL UI.

## Firmware boundary

Platform common code lives in `contracts/`, `core/`, `runtime/`, `protocols/common/`, `ui/common/`. Luban-Lite integration must link the SDK's `packages/third-party/lvgl` and `packages/custom/lvgl-aic`, and must not rebuild this repository's host LVGL submodule.

## Documentation

Project documentation is bilingual: every first-party document ships `X.md` (English) and `X.zh-CN.md` (Simplified Chinese); update both together. See the [bilingual documentation rule](docs/bilingual-docs.md).

Reference-Mixed combines CAN0 synthetic DBC, CAN1 fixed PDO and standalone CANopenNode SDO read/write without NMT/Heartbeat. Product startup services consume queued results outside protocol callbacks. See [SDO integration](docs/v0.3-phase4-canopen-validation.md).

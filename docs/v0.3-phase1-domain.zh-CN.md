# Forklift Meter Platform v0.3 — 阶段 1
> [English](v0.3-phase1-domain.md)

## 阶段

域语义加固。

## 变更

- `meter_core_apply()` 比较完整值，仅在值、时间戳、状态或来源变化时递增 `revision`。
- `meter_core_tick()` 使用每个信号的 `stale_ms`；零表示禁用自动超时，不存在运行时级别的兜底超时。
- 过期迁移、连接/代数变化、参数、故障和设置仅在真实状态变化时更新 `revision`。
- 来源仲裁接收完整的传入/当前 `meter_value_t` 值，包括时间戳、状态、值和来源标识。
- 现有产品和主机调用点使用双参数 `meter_core_tick(core, now_ms)` API。

## 测试

- `ctest --test-dir build --output-on-failure`：21/21 通过。
- 核心回归覆盖重复的相同信号/参数/故障写入、过期迁移修订号和来源仲裁。
- 现有架构、public-clean、DBC、双语 UI、测试夹具和 SDL 测试保持通过。

## 已知限制

- CANopen PDO/SDO 和自定义事务服务不属于本阶段。
- 本次仅主机侧的域变更未重新构建单板镜像。
- SDK 的 `origin` URL 仍为现有不可用的 `boa-w` 仓库，未做更改。
